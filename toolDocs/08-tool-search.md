# 08 搜索与目录工具：grep、find、ls

> 三个只读工具共用哲学：条数先限、字节再截、长行先砍、超限给继续动作。都尊重忽略规则，不打扰版本库。

## 8.1 grep：搜内容

### 参数

- pattern：字符串，必填。搜索模式，默认正则，字面量模式需开开关。
- path：字符串，可选，默认当前目录。目录或文件均可，目录则递归搜，文件则单文件搜。不存在直接报错。
- glob：字符串，可选。如星号点后缀、双星斜杠星号点测试后缀。透传给底层搜索器做文件过滤。
- ignoreCase：布尔，可选，默认 false。开则忽略大小写。
- literal：布尔，可选，默认 false。开则按字面量搜，不按正则。
- context：数字，可选，默认 0。大于 0 则每命中前后各带若干行，格式为匹配行用冒号，上下文行用减号。
- limit：数字，可选，默认 100。至少 1。达上限即停并杀搜索进程。

### 执行步骤

1. 确保搜索器可用。找不到则尝试自动下载，仍无则报错，文案大意是搜索器不可用且无法下载。
2. 解析搜索路径，判断是目录还是文件，路径不存在报错。
3. 拼搜索器参数：JSON 输出、行号、无色、含隐藏文件，按需加忽略大小写、字面量、文件过滤，最后加分隔符、模式、路径。
4. 起子进程，逐行读 JSON 事件，只收匹配事件，记文件、行号、行文本。计数达上限即杀进程并记上限标记。
5. 搜索器退出码非 0 非 1 且非因上限被杀，则按标准错误报失败。退出码 1 表示无命中，属正常。
6. 无命中返回无匹配占位，不算失败。
7. 有命中则格式化：无上下文直接用事件行文本，有上下文则回读文件补块。行文本先清回车，再按 500 字符砍长行并记长行标记。
8. 对全部输出做头部字节截断，行数不限因条数已限。拼提示：达条数上限则提示调大条数或收紧模式；字节截断则提示字节上限；长行被砍则提示用读工具看全行。
9. 细节带条数上限、长行标记、截断信息，有一项才带。

### 教学

- 描述写清返回文件路径加行号、尊重忽略规则、截断上限、长行上限。
- 简介为按模式搜文件内容，一句话。规则无，由通用规则覆盖。

## 8.2 find：找文件

### 参数

- pattern：字符串，必填。glob 模式，如星号点后缀、双星斜杠星号点配置后缀、源目录双星斜杠星号点测试后缀。
- path：字符串，可选，默认当前目录。目录不存在直接报错。
- limit：数字，可选，默认 1000。透传为最大结果数。

### 执行步骤

分两支：自定义文件匹配函数与默认外部查找器。自定义分支用于远端，默认分支用于本地。

自定义分支：检查路径存在，调自定义匹配，空则返回无文件占位。相对化路径为相对搜索根的 POSIX 风格，达上限记标记，字节截断，拼提示。

默认分支：

1. 确保查找器可用，无则报错。
2. 上溯查是否有版本库，有则用默认忽略感知，无则加无需版本库标记，保证版本库外仍尊重忽略文件。这是修复历史问题的关键细节。
3. 拼参数：glob 模式、无色、含隐藏、最大结果数。模式含斜杠则开全路径模式，缺前导双星斜杠则补，Windows 下把斜杠转字符组以兼容原生分隔符。
4. 起子进程逐行收路径，退出码非 0 但有输出仍继续，无输出才报失败。
5. 逐行去回车去空，相对化为 POSIX 风格，达上限记标记并给调大提示，字节截断给字节提示。

### 教学

- 描述写清返回相对搜索目录的路径、尊重忽略规则、截断上限。
- 简介为按 glob 找文件，一句话。

## 8.3 ls：列目录

### 参数

- path：字符串，可选，默认当前目录。文件而非目录直接报错，不存在直接报错。
- limit：数字，可选，默认 500。达上限即停并记标记。

### 执行步骤

1. 检查存在，非目录报错，读目录失败报错。
2. 大小写不敏感排序，保证跨平台稳定。
3. 逐项取状态，是目录加斜杠后缀。取状态失败跳过该项，不中断。
4. 达条数上限记标记。空目录返回空目录占位。
5. 拼字节截断，行数不限因条数已限。超限提示调大条数或字节上限。

### 教学

- 描述写清字母序、目录斜杠后缀、含点文件、截断上限。
- 简介为列目录内容，一句话。

## 8.4 复现要点

- 先定三默认值：搜索 100、查找 1000、目录 500。条数是第一道防线，字节是第二道。
- 搜索器与查找器做自动下载兜底，无则报不可用，不要静默降级为慢实现。
- 所有超限提示必须可行动：调大条数、收紧模式、读全行、换翻页。
- 相对化路径统一 POSIX 风格，Windows 反斜杠转斜杠，否则模型拼路径易错。
- 读文件回填上下文要走可插拔读，便于远端复用同一套缓存。
