## 成就系统与彩蛋

### 需求介绍

希望在现有对话能力之外，增加一套长期、轻量的正向反馈：记录用户与工具之间的累计互动，并在达成里程碑时给出即时反馈。基础维度包括用户消息累计字符数、累计创建会话数、累计使用 token 数、连续活跃日；另设几个偏"追求数值"的进阶项，例如单会话最高上下文连续使用量（跨 compact 合计）、单会话最高命中率。这些指标只用于回顾和激励，不改变对话主链的任何行为。

在呈现上，希望不只是冷冰冰的数字徽章，而是带一点趣味：隐藏成就、反差文案、主题色联动、集齐解锁等彩蛋玩法。整体体验必须克制——默认可关闭、不打扰、数据只留在本地，不做任何上报。

工程上希望保持标准化：成就逻辑独立成旁路模块，不直接插入引擎代码；复用已有的用量库、会话库和事件出口；任何统计或存储失败都不能影响对话。已确认现有数据底座足以支撑绝大多数指标，整体可行性高。

### 可能的实现顺序

| 阶段 | 范围 |
|---|---|
| P0 | 旁路骨架 + 累计类基础成就（token / 会话 / 字符 / 活跃日）+ 解锁提示 |
| P1 | 事件型成就 + 跨 compact 峰值 / 单会话命中率 |
| P2 | 隐藏成就、彩蛋、主题联动等趣味扩展 |

### 难度评级

| 类别 | 难度 |
|---|---|
| 累计类（token / 会话 / 字符） | 低 |
| 连续活跃日、单会话最高命中率 | 中 |
| 单会话最高上下文峰值（跨 compact 合计） | 中偏高 |
| 事件型成就与彩蛋 | 中 |

## roleplay 模式

### 需求介绍

希望在现有工具对话模式之外，新增一种 roleplay（角色扮演）模式。该模式下默认禁用工具调用（或按角色/场景白名单部分放开），让模型专注于人格演绎与叙事推进；支持导入常见的 AI 角色卡文件，解析其中的人格设定与世界观/世界书信息，作为该模式下的角色与背景来源。

体验上围绕"沉浸感"设计：前端为 roleplay 提供专门的布局样式，突出角色信息、世界书条目与事件记录，弱化工具与工程化元素。世界书与事件需要一套可增删改查的模块系统，方便用户在使用过程中维护背景设定与剧情走向。边界上，模式切换不应污染普通对话的上下文与设置；角色卡导入失败应可安全回退，不破坏当前会话。

工程上保持旁路化：角色卡解析、世界书与事件的存储独立成模块，复用已有的会话与文件能力；工具开关沿用现有权限/配置机制而非另起一套。模式相关状态本地保存、不做上报，任何解析或存储异常都不能影响主对话链路。角色卡来源多样、格式差异大，解析容错与内容安全是需要重点考虑的约束。

### 可能的实现顺序

| 阶段 | 范围 |
|---|---|
| P0 | 模式框架 + 工具禁用/白名单 + 基础角色卡导入与人格解析 |
| P1 | 世界书与事件的 CRUD 模块 + roleplay 专用前端布局 |
| P2 | 多角色卡管理、世界书高级特性（条目优先级/触发条件）与体验打磨 |

### 难度评级

| 类别 | 难度 |
|---|---|
| 工具禁用/部分放开 | 低到中 |
| 角色卡导入与人格解析 | 中（全兼容 PNG 内嵌卡则中偏高） |
| 世界书与事件 CRUD 模块 | 中偏高 |
| roleplay 专用前端布局 | 中 |

## server-ctrl 模式

### 需求介绍

希望新增一种 server-ctrl（服务器管控）模式，把 SSH 运维与模型协作放到同一界面。用户可保存多份 SSH 连接配置，并为每条连接单独设置是否经由代理；连接信息本地持久化（凭据不明文存储、不进入模型上下文）。界面一侧展示 SSH 命令行信息并允许用户直接交互输入命令，另一侧展示与模型的 chat，用户也可用自然语言下达任务。

在该模式下，模型通过一组专用工具"观察"和"操作" SSH：读取屏幕当前内容、获取上下文、写入命令等，从而实现"说任务—模型执行—用户看结果"的闭环。出于安全，所有由模型下发的命令都要经过危险关键词检查，命中时弹出 Dialog 由用户二次确认后才执行（检查与确认须与写命令同批，不可后置）；用户手动输入的命令不受此限制。模式应保持连接隔离、过程可追溯。

工程上，SSH 连接与代理配置的存储、终端交互、模型专用工具与危险词检查宜各自独立成模块，复用现有的工具注册与权限机制；危险词规则可配置而不写死。网络与终端异常不能影响模型 chat 主链路，连接管理遵循本地优先、不明文上报的原则。该模式涉及真实的远程执行能力，误操作与凭据泄露风险高，安全边界与确认机制是首要约束。

### 可能的实现顺序

| 阶段 | 范围 |
|---|---|
| P0 | SSH 连接配置保存 + 单连接代理开关 + 命令行展示与直接交互 |
| P1 | 模型 chat 侧 + 专用工具（读屏/取上下文/写命令）+ 危险检查与二次确认 Dialog（随写命令同批） |
| P2 | 规则可配置、过程审计与体验打磨 |

### 难度评级

| 类别 | 难度 |
|---|---|
| SSH 配置保存与单连接代理开关 | 中 |
| 终端展示与直接交互 | 高 |
| 模型专用工具读屏/写命令闭环 | 高 |
| 危险关键词检查与二次确认 | 中偏高 |
