# 流→稳切换不能靠两个独立 watch 拼原子操作

> 日期：2026-11-22 · 场景：CefSharp 跨代桌面端 Web.Client 时间轴，模型回答结束的 300ms 交接窗。

## 现象

`TurnCompleted` 之后，模型回到贴底跟随的用户会被甩到很远，且不再自动回底；开发者工具里能看到同一份回答在 DOM 中存在约 300ms 的两份。

## 根因（四个叠加，缺一不可复现全部症状）

1. `finishTurn` 里 `reloadNow` 先把稳态轮挂进摘要区，`doClear` 在 300ms 后才撤流态容器。两者是两个独立事件，中间没有「同容器交接」，于是双份正文并存，撤下瞬间落差 ≈ 整个流态体（长思维链 + 多张工具卡，几百到上千 px）。
2. 投影层只透传 `{kind,key,text,card}`，把落盘 `tag` 丢了。想按「正文 / 过程」分组收缩时失去真相源，退回「数组最后一个 text seg」会在多轮迭代下误判。
3. 摘要插入导致的 `scrollHeight` 增长无人补偿——滚动 watch 读的是 `projection: null` 的条目数，恒为 0；唯一活着的滚动入口在 300ms 后撤下时才触发一次。
4. 几何变化被当成「用户上翻」：`onTranscriptScroll` 只凭距底距离就 `releaseFollow()`。交接期距离短暂 > 容差 → 跟随被解除 → 300ms 后那次 `scheduleToBottom` 检查 `pinnedRef=false` 直接跳过。用户被留在半路。

## 修复口径（四条铁律）

1. **同容器交接**：把 user / process / final 三槽包进唯一容器，正文全程单份且满高；只收缩过程段 wrapper。摘要区刚完成轮的 final 槽在交接期隐藏，换手时同一帧撤 Live、显稳态。
2. **正文不搬运**：Live 正文从挂载到换手全程不卸载；稳态盒通过 `initialMarkdown` 用同一份文本作种子，避免 `finalPreview` 纯文本 → markdown 的二次跳。分组判据用 `tag`，兜底用 `blockId === finalBlockId`，禁止数组末位。
3. **高度动画是实测 px**：CSS 不能 `height: auto → 0`。读 `offsetHeight` → 写死 px → 双 rAF 后置 0 + `opacity:0` + `overflow:hidden`；`prefers-reduced-motion` 直通。收缩容器必须独立于带 `content-visibility:auto` 的轮容器，否则测量失准。
4. **锁「自动解除跟随」，不锁用户**：交接窗内置锁，`onTranscriptScroll` 的几何分支跳过 `releaseFollow()`；wheel/touch/keydown 仍立即解锁（用户意图最高）。结束解锁后 `forceToBottom()`，此时高度已稳定，瞬移不再产生可见跳变。

## 守卫必须断言行为

曾经有个「红线测试」用正则检查 CSS 文本里有没有 `position: absolute`。过渡组件被整体删除、CSS 变成死代码后，测试一直绿——**检查字符串，不是行为**。升级口径：挂载级断言交接容器存在、正文实例数为 1、过程 wrapper 高度序列单调递减、`pinnedRef` 在 lock 期不被几何变化解除。高度/滚动的 jsdom 断言只能做兜底，真正的行为靠 H4 60fps 逐帧人工验收。
