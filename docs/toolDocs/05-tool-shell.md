# 05 命令执行工具：bash 与 powershell

> 命令工具是能力最强也最危险的工具。设计目标：流式可见、可中止、可超时、大输出不爆上下文、环境可审计。

## 5.1 参数

- command：字符串，必填。要执行的完整命令。跑在当前工作目录，返回合并后的标准输出与标准错误。
- timeout：数字，可选，单位秒。无默认值，不给则一直跑到结束或中止。必须为有限正数，换算毫秒后不得超约 24 天上限，否则报参数无效。超时后杀进程树并报超时秒数。

两个工具参数同形，共用一套执行骨架，仅外壳配置不同。

## 5.2 外壳差异

- bash 版：标签与提示符为美元符，临时文件前缀为命令前缀，指南为可查看会话环境变量。外壳解析走通用 shell 配置，支持自定义 shell 路径与命令前缀。
- powershell 版：在命令前自动加一段设置输出为 UTF-8 的前缀，提示符为 PS 引导，临时文件前缀独立。外壳解析走 PowerShell 配置，自动找可用 PowerShell。会话环境变量指南相同，但可独立开关。

命令前缀指每次执行前拼在用户命令之前的 setup 命令，如初始化环境。显式 shell 路径用于锁定解释器。

## 5.3 进程执行步骤

1. 校验超时合法性，检查工作目录存在，不存在直接报错并注明无法执行命令。
2. 拼环境变量：先拷贝当前进程环境，再删掉会话标识、会话文件、供应商、模型、推理等级五个旧值。若开启会话环境暴露且有扩展上下文，则重填会话编号、会话文件、模型供应商、模型编号、推理等级。用于命令里审计与自适应。
3. 跑 spawn 钩子，允许改命令、工作目录、环境。用于扩展拦截改写。
4. 起子进程：工作目录为解析后目录，非 Windows 用独立进程组以便杀树，Windows 隐藏窗口。命令传输分两种：支持标准输入传输的把命令写进标准输入，否则拼进启动参数。记录子进程号以便追踪。
5. 流式收标准输出与标准错误，统一进输出累积器，节流推增量回调。先推一次空内容占位，保证界面先画框。
6. 注册中止监听，中止即杀进程树。注册超时计时，超时即杀进程树并记超时标记。
7. 等进程退出，不继承父句柄挂起。退出码为空则按信号换算为 128 加信号号，无信号则记 1，防止误判成功。
8. 关增量计时，落输出快照，关临时文件，算墙钟秒数保留一位小数。

## 5.4 输出与截断

- 模型可见输出取尾部，默认 2000 行或 50KB，留末尾以便看报错与结论。截断时追加提示，含显示起止行、总行数、字节上限、全量文件路径。末行半截会注明该行实际大小。
- 空输出用无输出占位，避免空块。
- 程序可见全量输出另读，最多 1MB。超 1MB 取首尾各半加省略字节数标记。结构化结果含全量文本、是否截断、全量文件路径、退出码、墙钟秒数。
- 截断全量落临时日志文件，路径回给模型，模型可用读或命令二次查看。临时文件在快照持久化时确保创建。

## 5.5 成功与失败判定

- 退出码为 0：成功，内容为输出文本，细节带截断信息，结构化带全量。
- 退出码非 0：失败，内容为输出加空行加退出码说明，细节与结构化同成功，失败标记置 true。脚本仍可读结构化拿到输出，不丢数据。
- 退出码为空：抛错，文案为命令结束但无退出码。
- 执行中抛中止：文案为命令已中止。抛超时：文案为命令超时秒数，均带已产出文本。
- 工作目录不存在、shell 起不来：直接抛错，不进输出累积。

## 5.6 给模型的描述与规则

- 描述写清在当前工作目录执行、返回标准输出与标准错误、截断留末尾上限、全量落临时文件、可选超时秒数。
- 规则加一条可查看会话环境变量，模型据此用环境变量做自适应，如按模型切换命令。
- 可用工具段简介为执行命令或执行 PowerShell 命令，一句话。
- 若编程组合里只有命令没有搜索目录工具，系统规则自动加一条用命令做文件列表搜索查找，避免模型不知道 fallback。

## 5.7 复现要点

- 先做 spawn、流式、杀树、超时、中止、退出码判定，即可跑通。
- 再做输出累积器、尾部截断、全量落盘、结构化 1MB 拼接。
- 环境注入与 spawn 钩子最后做，用于审计与扩展。
- 杀树在 Windows 与非 Windows 行为不同，务必按平台处理，否则中止会留孤儿进程。
