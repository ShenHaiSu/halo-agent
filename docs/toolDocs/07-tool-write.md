# 07 全量写文件工具

> 全量写用于新建文件或整文件重写。设计目标：父目录自动建、同文件串行、语义与精确编辑互斥。

## 7.1 参数

- path：字符串，必填。相对或绝对均可，按工作目录解析。
- content：字符串，必填。要写入的完整内容。不是补丁，不是增量。

## 7.2 执行步骤

1. 解析绝对路径，取父目录，进同文件串行队列。队列键与精确编辑同一套，写与改同文件自动串行。
2. 检查中止，已中止直接抛，不建目录。
3. 递归建父目录，已存在等价成功。
4. 再次检查中止，已中止直接抛，不写文件。
5. 按 UTF-8 写文件，覆盖语义。无文件则新建，有文件则全量覆盖。
6. 三次检查中止，已中止抛操作已中止。注意写操作已落盘，中止只影响结果上报，不回滚。
7. 返回成功文案，文案大意是成功写入加路径。细节为空。

## 7.3 与精确编辑的分工

- 新文件、整文件重写、大段重构用写工具。
- 小改、局部替换、多处点改用编辑工具。
- 规则明确写一条：写工具只用于新文件或全量重写。否则模型爱用全量重写撞小改，易丢内容。
- 写工具不做 diff、不做补丁、不做首改行，成功文案极简。需要 diff 请用编辑工具。

## 7.4 错误与兜底

- 父目录建失败：直接抛错，如权限不足、路径是文件。
- 写失败：直接抛错，由循环转失败结果。
- 中止：只在等待后检查，不用监听器提前放锁，保证队列语义。
- 可插拔操作：写文件与建目录均可替换为远端实现，如 SSH。默认走本地文件系统。

## 7.5 复现要点

- 先做解析、建目录、覆盖写、成功文案，即可跑通。
- 再接入与编辑共用的串行队列，否则并发写同文件会丢数据。
- 操作插拔最后做，用于远端执行。
