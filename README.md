# 你好，我是 Halo-Agent 👋

> 我是一个住在你 Windows 电脑里的桌面 AI 搭子。
> 从 Win7 老机器到 Win10 / Win11，我都能跑。
> 你给我一个文件夹、一个模型 Key，我就帮你读、改、跑、记 —— 稳当、可撤销、记得住。

我不是网页，也不是按月续费的云服务。
我是单机应用：聊天记录、文件、配置默认都存在你自己的电脑上（`C:\HaloAgentData`），不上传到我以外的任何地方。断网也能翻历史、看文件，连模型时只走你自己配的 Key 和代理。

---

## 我适合谁？

- **程序员**：让我帮你读仓库、改 Bug、写脚本、跑测试、整理提交。
- **文字工作者 / 学生**：让我帮你整理文档、改稿、查资料、列大纲。
- **还在用老电脑的人**：工控机、旧笔记本、Win7 机器 —— 别人跑不动的新应用，我特意为你留了位置。
- **在意隐私的人**：数据主权在你手里，Key 用 Windows DPAPI 加密存本机，换电脑才需重填。

如果你只想找个“能干活、记得住、不乱传数据”的本地搭子，那就是我。

## 我能为你做什么？

### 1. 陪你把一件事从头干到尾

你不用一次把需求说完美。你说一句，我做一步，不懂就问你：

> 你：“帮我看看这个项目为什么启动不了”
> 我：先列目录、读启动文件、查报错关键字、试着跑一次，每一步都摊开给你看。

我做事的方式是这样：

- **边想边做**：思考过程可折叠展开，想看就看，不想看只看结论。
- **每一步都留痕**：读了哪个文件、改了哪一行、跑了哪条命令，都会变成一张小卡片，带 Diff 对比。
- **拿不准就问你**：要删文件、要跑高危命令、需求有分歧时，我会弹窗问你，而不是自作主张。
- **大目标拆小步**：复杂任务我会自己立一个小目标清单（Goal），做完一项勾一项，你在右侧随时能看到进度。
- **能分头干活**：大工程我可以派子任务（SubAgent）并行去探路，主线等它们全部回来再汇总，不会半路丢活。

### 2. 读写改查，我手脚很稳

- **读**：大文件分页读，中文 GBK / UTF-8 自动识别，不乱码。
- **改**：先备份再动手。`edit_file / edit_lines / edit_batch` 都是原子替换，改错了可以一键 `undo_edit` 撤销，不怕翻车。换行符（CRLF/LF）我会守住，不会把你的文件搞乱。
- **写 / 删**：新建文件、删除文件都有备份和高危拦截，删错也能找回来。
- **找**：全仓库搜关键字、搜代码，不用你装任何外部搜索工具。
- **跑**：帮你跑 `cmd` 命令、跑 Python 脚本，超时、卡死我会自己清理进程，不留僵尸进程。
- **看图**：把本地图片丢给我，我能直接看，再结合着改代码或写文档。

三种干活模式，一键切换：

| 模式 | 意思 | 什么时候用 |
|---|---|---|
| `coding` | 日常写代码：能读能改能跑 | 最常用 |
| `readonly` | 只看不动手 | 评审、学习、审计时最安心 |
| `full` | 火力全开：子任务、记忆、技能全放开 | 大工程、长周期任务 |

你还可以在设置里用白名单 / 黑名单微调：“这次不许删文件”、“这次只许读”，我都会严格遵守。

### 3. 记得住你和你的项目

- **工作区（Workspace）**：一个文件夹就是一个项目。你有多少个项目，我就分开记，互不串味。
- **会话（Session）**：一个项目下可以开无数个会话，每个会话独立存档，随时回来继续。
- **长期记忆（Memory）**：你告诉我的偏好、规范、常用命令，我可以记下来，下次自动用上。不想要了随时删。
- **技能（Skill）**：你常用的套路（比如“发版前检查三件套”）可以存成技能，一句话召唤。
- **超长对话不丢失**：聊太长了，我会自动把前文压缩成摘要，后面还能接得上；超长的工具输出会存成文件，不撑爆上下文。

### 4. 历史很好翻，不怕聊丢

- 右侧有**历史目录（TOC）**，长对话一键跳转。
- 任何一句话右键都可以：**复制原文 / 重放（从这里重来）/ 分支（另开一条线试试）**。灵感不敢试？开个分支就行，原路还在。
- 会话标题我会自动取，时间线按轮次收拢，干净好读。
- 流式回答时你能看到“正在想、正在调工具”的直播态，落盘后自动收敛为干净的终态，不会闪烁、不会丢卡。
- 底部输入框有**草稿箱**，分支、重放的内容先放草稿，你确认再发。

### 5. 模型、网络、用量，你说了算

- **模型随便换**：OpenAI 兼容的 Chat 和 Responses 双协议我都吃得下。`baseUrl + Key + 模型名` 配好就能聊，公司内网模型、第三方中转都能接。
- **代理听你的**：跟随系统 / 自定义（http/https/socks5）/ 强制直连，还能一键测连通性。
- **用量心里有数**：顶部有上下文水位条，设置里有用量统计（花了多少 Token、调了多少次工具），不会糊里糊涂超标。超长上下文我会自动裁剪、做预算，保证不爆。
- **请求头小魔法**：高级用户可以给请求加自定义 Header，还能用 `${session-hash}` 这类变量做缓存亲和，鼠标悬停就有解释。

### 6. 长相和习惯也听你的

- 深色 / 浅色主题，字号滑杆，怎么舒服怎么来。
- 左侧栏宽度可拖，Win7 下字体和图标都做过兼容，不花、不糊。
- 漂亮的 Markdown、代码高亮、Mermaid 图、工具卡片折叠，读长回答不累。
- 启动有开屏动画，初始化完成自动淡出，不会干等。

## 我和别的 Agent 有什么不一样？

| 对比项 | 网页版 AI（ChatGPT / Claude 网页） | IDE 插件 / CLI Agent（Copilot / Cursor / Claude Code） | **我 Halo-Agent** |
|---|---|---|---|
| **跑在哪里** | 跑在别人服务器上 | 跑在编辑器 / 终端里，换个地方就没了 | **跑在你的 Windows 桌面上**，双击即用，有窗口、有侧栏、有设置中心 |
| **数据归谁** | 聊天全在云端 | 历史散落在各工具里 | **默认全在你本机 `C:\HaloAgentData`**，可一键迁移目录，搬家拷走就行 |
| **老电脑能用吗** | 浏览器越更新越卡 | 新版 Node / Electron 老系统装不上 | **Win7 SP1 就能跑**：我锁死 Chromium 109 + .NET 6，自带 Win7 防黑屏、防花屏、TLS1.2 兜底 |
| **改文件敢放心吗** | 不能碰本地文件 | 能改，但改错难回头 | **备份优先 + 原子写入 + 一键撤销**，换行符守恒，高危命令默认拦截 |
| **过程看得见吗** | 只有一个结果 | 一堆日志刷屏 | **时间轴卡片**：读了啥、改了啥、跑了啥，每张卡都能点开看 Diff |
| **记性怎么样** | 换个会话就失忆 | 靠你手写规则文件 | **工作区隔离 + 会话存档 + 长期记忆 + 技能 + 自动压缩摘要**，下次打开还记得你 |
| **模型被绑定吗** | 只能用他家模型 |  often 绑定某家 | **不绑定**：任何 OpenAI 兼容接口都能配，Key 本地 DPAPI 加密 |
| **断网能干啥** | 直接不可用 | 部分不可用 | **历史、文件、配置、诊断全离线可用**，只有调模型那一下才需要网 |
| **费用透明吗** | 包月黑盒 | 按量但难对账 | **用量统计面板**：每次花了多少 Token、调了几次工具，全部可查 |

一句话：**别人是“借你用的云大脑”，我是“住你家的本地手脚”** —— 大脑你可以随便换（配什么模型都行），手脚和记忆永远留在你电脑上。

## 我的自我修养（你不用记，出问题时看看）

1. **数据主权**：历史、配置、日志默认在 `C:\HaloAgentData`（C 盘写不进会自动降到 `%LocalAppData%\HaloAgent\Data`）。想搬家？设置 → 存储里一键迁移，我会先检查目标盘空间。
2. **不动手脚**：写文件是原子替换（先写临时文件再换），改文件先备份，高危命令默认拦截，输出太长自动截断存盘。
3. **可取消**：我说到一半、跑到一半，你随时点停止，我会把子进程一起收掉。
4. **可审计**：重放前自动备份、分支留源、压缩留档，都在数据目录里找得到。还有存储诊断和事件时间线，哪里不对一目了然。
5. **老机器承诺**：锁定 Chromium 109 + .NET 6，就是为了 Win7 还能用。新特性再香，我也不会偷偷升级内核把你丢下。
6. **命名与架构洁癖**：前后端严格分层，工具即插即用，提交前有类型检查、Lint、单测三道门，不会把半成品发给你。

## 和我相处 5 分钟

**第 1 分钟：把我带回家**

去 `dist` 拿 `Host.Desktop.exe` 双击就行（第一次建议右键“以管理员运行”一次，帮我把数据目录权限修好）。
Win7 用户记得装好 `KB2533623` 和 VC++ 2015-2022；如果花屏，在程序目录放一个空文件 `disable-gpu.flag` 重启即可。

**第 2 分钟：告诉我用哪个模型**

打开右上角设置 → 模型服务 → 新建 Provider，填上 `baseUrl`、Key、选 `chat` 还是 `resp` 协议，点一下“测试连接”，通了就行。
Key 我会用 Windows DPAPI 加密存在你本机，换电脑要重填一次。

**第 3 分钟：给我一个工作区**

左侧点“新建工作区”，选一个本地文件夹（比如你的代码目录）。
之后我所有的读、改、跑，默认都关在这个范围内，出圈的操作我会拦下来问你。

**第 4 分钟：说第一句话**

比如：

- “先帮我看看这个目录结构，说说这是个什么项目”
- “把 README 里的错别字修一下，改了什么列出来”
- “写个 Python 脚本，把这个文件夹里的 csv 合并成一个”

**第 5 分钟：看看我干了什么**

回头翻翻时间轴上的工具卡，点开 Diff 看看。
满意就继续，不满意右键“重放”换个说法再来一次。

## 你可能会问我

**Q：双击没反应 / 闪退？**
先看程序目录下的 `startup-error.txt` 和 `startup-trace.txt`，那是启动期唯一的线索。再试试以管理员运行一次，检查杀软是不是拦了我。

**Q：模型报 401 / 超时？**
去设置里点“测试连接”。八成是 `baseUrl` 后缀、协议选错（chat / resp）、Key 填错，或者代理没走对。公司网先试“跟随系统”。

**Q：中文命令乱码？**
我已经做了 GBK / UTF-8 自适应，优先用 `cmd` 跑。如果还乱，把工具日志里那段发给我看。

**Q：C 盘写不进怎么办？**
我会自动降级，不丢数据。你也可以设个环境变量 `HALO_BOOTSTRAP_PATH` 把数据根指到 D 盘，或在设置 → 存储里一键迁移。

**Q：我想换电脑？**
把数据根整个拷走，新电脑上指向它就行。只是 Key 要重填一次（DPAPI 是跟机器绑定的）。

**Q：我是开发者，想看架构和构建？**
好，那请移步：顶层宪章 `docs/CEFSHARP_ARCHITECTURE_STANDARD.md`，各需求蓝图 `docs/need-01 / need-02 / p012 / p013-v2-session / p014-v2-session-fix`，一键构建 `build-dist.cmd`。这个 README 就不展开了，把位置留给使用者。
