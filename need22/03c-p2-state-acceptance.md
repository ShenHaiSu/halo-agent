## 2. 验收矩阵

| # | 验收项 | 标准 | 方法 |
|---|---|---|---|
| C1 无双影 | 流式期正文只出现一次；`data-row-id` 无重复 | 双协议各一轮录屏 + DOM 断言 | chat/responses 各一轮 |
| C2 无竞态 | 快切 5 次，视图与顶栏 session 一致，无串台 | 快切脚本 + `activeSessionId` 断言 | 自动化 |
| C3 幂等 | 连点发送只产生一轮，第二发 toast | 双发脚本 + 后端轮数计数 | 连点 fixture |
| C4 问询 | A 问询切 B 不错票；badge 提示；切回可继续 | 双会话问询 fixture | 手工 + 断言 |
| C5 中断 | 取消后无残留流式卡；失败有重试按钮 | 取消/断网两组 | 手工 |
| C6 无视觉回归 | 像素级不变（折叠/右键/复制口径不变） | 回归截图对比 | 截图 diff |
