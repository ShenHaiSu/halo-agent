## 2. 分阶段回滚

| 阶段 | 回滚命令 | 代价 | 备注 |
|---|---|---|---|
| P0 | `git revert <P0>` | 零（只加探针+单测） | 基线数据保留在 06 §2 表格 |
| P1 | `git revert <P1>` | 中（单轨切回双轨，用户回到“重复但可用”） | 回滚后 pill 消失、旧 active 容器恢复 |
| P2 | `git revert <P2>` | 低（Map 改回数组，渲染仍是单轨 P1 形态） | 可只 revert 后端节流提交，保留前端批处理 |
| P3 | `git revert <P3>` | 低（markdown/滚动回到旧逻辑，单轨保留） | 长会话重新变卡，但功能正确 |
| P4 | `git revert <P4>` | 零（只删死代码） | 死代码回来了，功能无变化 |

跨阶段回滚顺序：逆序（P4→P3→P2→P1），禁止跳序。
