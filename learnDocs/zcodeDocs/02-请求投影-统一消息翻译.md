# 02 请求投影：统一消息翻译成各协议形态

> 位置对应：请求发出前，把 `ModelInputMessage[] + ModelToolContract[]` 翻译成 SDK 要的 `messages/tools`。所有协议差异只允许出现在这里。

## 1. 总入口形态（伪代码）

```ts
function buildSdkRequest(req: ModelTextRequest, ctx: {
  apiFormat?: string;          // 即 ProviderApiType，由 providerOptions 透传
  providerKind: SdkKind;
  providerOptions?: Record<string, unknown>;
  inputFormat?: { text?: boolean; image?: boolean; video?: boolean };
}) {
  return {
    model: ctx.model,
    messages: toSdkMessages(req.messages, ctx),
    tools: toSdkTools(req.tools, ctx),
    toolChoice: req.toolChoice,
    temperature: req.temperature,
    // ... topP/topK/penalties/stopSequences/seed
    providerOptions: mergeProviderOptions(ctx.resolvedOptions, req.providerOptions),
    headers: mergeHeaders(ctx.staticHeaders, attributionHeaders(ctx)),
    maxRetries: 0, // 重试由自家 runner 做，SDK 不重试
  };
}
```

`apiFormat` 的来源：`providerOptions.apiFormat`，在分发层写入 `providerOptions = { apiFormat: config.api.type }`。请求层用 `options.apiFormat ?? options.providerOptions.apiFormat` 解析。

## 2. System 合并：只有 Chat 兼容端需要

```ts
function normalizeSystemMessages(msgs: ModelInputMessage[]): ModelInputMessage[] {
  if (providerKind !== "openai-compatible") return [...msgs];
  let n = 0;
  while (msgs[n]?.role === "system") n++;
  if (n <= 1) return [...msgs];
  const head = msgs.slice(0, n);
  const last = head[head.length - 1];
  return [
    {
      role: "system",
      content: head.map(m => messageToText(m.content)).join(""), // 按原顺序拼，不加空白
      ...(last.cacheControl ? { cacheControl: { ...last.cacheControl } } : {}),
    },
    ...msgs.slice(n),
  ];
}
```

为什么：旧式 Chat 模板只认一个开头 system；Anthropic 为缓存边界故意保留多条。合并只发生在序列化边界，不改会话事实。

## 3. Responses 无状态回放：剥离 reasoning 引用

触发条件（必须同时满足）：

```text
providerKind == openai
AND apiFormat == openai-responses
AND providerOptions.openai.previousResponseId 不存在
AND providerOptions.openai.conversation 不存在
AND providerOptions.openai.store !== false
```

动作：丢弃 `content[].type==reasoning && providerOptions.openai.itemId` 存在的块。

```ts
function toAssistantParts(blocks: ContentBlock[], ctx: Ctx) {
  return blocks.flatMap(block => {
    if (block.type === "reasoning") {
      if (shouldStripStoredReasoning(ctx) && hasStoredItemId(block)) return [];
      if (block.text === "" && isEmpty(block.providerOptions)) return []; // 空壳
      return [{ type: "reasoning", text: block.text, ...providerOptionsForReasoning(block, ctx) }];
    }
    if (block.type === "text" && block.text !== "") return [{ type: "text", text: block.text }];
    // image/video/file/resource_link 在 assistant 侧一律文本化，不回放二进制
    return textOf(block) ? [{ type: "text", text: textOf(block) }] : [];
  });
}
```

原因：部分 Responses 兼容端不支持无 `previousResponseId` 时回放 `store=true` 的 reasoning `item_reference`，会直接 5xx。

## 4. 空工具名占位

```ts
function projectToolName(name: unknown, ctx: Ctx): string {
  if (typeof name === "string" && name.trim() !== "") return name;
  const apiFormat = resolveApiFormat(ctx);
  if (apiFormat !== undefined) return apiFormat === "anthropic-messages" ? name : "empty_tool_name";
  return ctx.providerKind === "anthropic" ? name : "empty_tool_name";
}
```

- OpenAI wire 不接受空 function name，历史中的原始名仍保留给 Anthropic 回放，占位只在投影边界生成。
- 工具消息缺 `toolCallId/toolName` 直接抛 `InvalidModelRequest`，不在下游猜。

## 5. 用户消息：媒体与空 content

```ts
const EMPTY_USER_FALLBACK = "(no content)";

function toUserContent(content: string | ContentBlock[], ctx: Ctx) {
  if (typeof content === "string") return content || EMPTY_USER_FALLBACK;
  const parts = content.flatMap(b => toUserPart(b, ctx));
  return parts.length > 0 ? parts : EMPTY_USER_FALLBACK;
}

function toUserPart(block: ContentBlock, ctx: Ctx) {
  switch (block.type) {
    case "text": return block.text ? [{ type: "text", text: block.text }] : [];
    case "reasoning": return block.text ? [{ type: "text", text: block.text }] : [];
    case "image": {
      if (ctx.stripMedia) return [{ type: "text", text: placeholderOf(block) }];
      if (!inputFormatAllows("image", ctx)) return [{ type: "text", text: unsupportedText(block) }];
      const data = dataUrlToData(block.dataUrl);
      if (!data) return [{ type: "text", text: "ERROR: Image file is empty or corrupted." }];
      return [{ type: "image", image: data.bytes, mediaType: block.mediaType }];
    }
    case "video": {
      // SDK 无 video part 类型，用 file part + video/* mediaType，由补丁转 video_url/video block
      // 其余同 image
    }
    case "file": {
      if (block.text) return [{ type: "text", text: block.text }];
      // ... 同 image/video，dataUrl -> { type:"file", data, filename, mediaType }
    }
    case "resource_link": return [{ type: "text", text: `[Resource: ${title ?? uri}]` }];
  }
}
```

附件-only query 拆出 prompt attachment 后可能剩空 user content，空白占位又可能被 provider trim 判缺 prompt，所以用固定 `"(no content)"`，且只在 wire 边界加，不改会话事实与标题种子。

## 6. 工具声明投影

```ts
function toSdkTools(contracts: ModelToolContract[] | undefined, ctx: Ctx) {
  if (!contracts?.length) return undefined;
  const entries = contracts.flatMap(c => {
    if (c.providerNative) return toNativeTool(c, ctx); // 如 WebSearch，只在 anthropic 首方放行
    const strictSchema = resolveStrictSchema(c, ctx);  // strict 仅 anthropic 首方模型
    return [[c.name, {
      description: c.description,
      inputSchema: jsonSchema(normalizeSchema(c, ctx)),
      ...(strictSchema ? { strict: true } : {}),
      providerOptions: ctx.providerKind === "anthropic"
        ? { anthropic: { eagerInputStreaming: false } } // 兼容网关拒多余字段
        : undefined,
    }]];
  });
  return Object.fromEntries(entries);
}
```

两条硬规则：

1. `strict` 任一条件不满足就发原 schema，不给兼容端发陌生字段。
2. `requiresMfjsToolSchema` 时把 `#/properties/...` 引用提升到 `#/$defs/zcode_ref_N`（某些网关只认 `$defs`）。

## 7. 抄写清单
