## 1. 联调排错表

| 现象 | 先查 | halo 映射 |

| 兼容端整响应被拒 | Responses JSON 兼容层是否补 `id/annotations` | `ResponsesJsonCompat.cs` 是否生效（G2） |
| 续轮 5xx / reasoning 引用错 | 是否剥离无状态 reasoning 引用 | halo 暂无引用设计；若服务端新增引用必须补（P2） |

## 2. 验收标准（DoD）

- P0：`Stage03GatewayAndStreamTests` 新增用例（缺字段修补/403 业务码/后缀归一/空名占位/组装器四分支）全绿；`LlmGatewayClient` 无回退分支。
- P1：C# 与 TS `coalesce` 等价单测同 fixture 全绿；`applyAll(s,coalesce(ds))===applyAll(s,ds)`；取消/切换模型无旧流污染；断档重订阅后终态一致；`replayable` 档回放只看定稿可渲染。
- P2：未知工具走 `FallbackCard`；半截 JSON 不可执行；复制是整轮合并；审批入口唯一（`pendingInteractions`）；长会话虚拟列表不卡；`data-row-id` 框选/埋点可用。

## 3. 回滚线

- 任何阶段保留 `DeliveryProfile{legacy,zcode}` 开关 + 后端特性旗。P1 灰度先单会话开 zcode 行增量，其余会话走旧双事件；出现漂移一键切回 legacy（快照/行增量只影响传输，不动 `messages.jsonl`，回滚零数据迁移）。
- 禁止事项：回滚时不删已落盘快照字段（`seq/revision` 只增不减）；不把 `agentStore` 瘦身与投影存储上线放在同一版本（分两版，先加后删）。
