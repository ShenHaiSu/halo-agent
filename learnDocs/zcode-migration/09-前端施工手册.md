# 09 前端施工手册（Vue/TS）

> 按顺序做，每步可独立提测。坑位用 ⚠️ 标出。

## Step 1 投影存储（F1）

1. 新建 `src/stores/projectionStore.ts`：
   - `state{snapshot,subscriptionId,status}`；`onSnapshot(s)` 整体替换；`onFrame(f)` 仅 `f.fromSeq===snapshot.seq` 时 `apply`，否则 `resubscribe(snapshot.seq)`；
   - TS 版 `applyDelta/coalesce` 与 C# 逐字节一致（同 fixture 单测）；
   - `optimisticCommands{commandId}` 只展示输入气泡，2s 无权威确认只重订阅、不重发。
2. `workspaceStore.loadSessionMessages` 改为快照源；`rows/range` 前插去重后按 `rowId` 升序。
3. 行引用共享：`apply` 未变行保引用，虚拟列表按引用判等跳过渲染。
- ⚠️ 存储只有订阅推送能写，组件只读；`snapshot` 永不 merge。
- ⚠️ `fromSeq` 对不上禁止本地补偿（猜增量是长会话漂移主因）。

## Step 2 轮次组装（F3）+ agentStore 瘦身（F2）

1. `utils/turnGroup.ts` 加四条（见 06 §2）：header 权威 + 空 reasoning 过滤 + `EnterPlanMode` 过滤 + 轮尾 marker/artifact 摘出；无 header 快照保留 `isRunningWork` 兜底。
2. `agentStore.ts` 瘦身：删 `ToolCallUpdated/Args/Completed` 拼状态逻辑，改为读投影行；保留 `turns[sessionId]` 分桶、`telemetry/liveEst/subAgents`、`finishTurn→turn-archived→清流式容器` 消双影、`dirtyPersisted` 语义。
3. 删 `useTimelineGroups.ts` 遗留版引用（统一用 `turnGroup` 版），避免两人各说各话。
- ⚠️ 轮是否运行只看 `turnHeader.state`，不嗅探文本、不按时间推导。
- ⚠️ `hiddenToolCallIds` 在过渡期保留（藏本轮持久灰块），终态行合一后删除。

## Step 3 渲染（V1~V4）

1. 新建 `utils/toolCallRowToCard.ts`：
   - `STATUS_MAP{inputStreaming:pending,pendingApproval:pending,running:in_progress,success:completed,error:failed,cancelled:stopped}`；
   - `previewFromInputText`：空→`{undefined,false}`，可解析→`{input,true}`，半截→`{partial,false}`（可展不可执）；
   - `resolveRenderer(toolName)`：Read/Edit/Write→FileCard，Bash/Execute→CommandCard，Agent/Task→AgentCard，AskQuestion→QuestionCard，余→`FallbackCard`（显示原文 JSON，永不白屏）。
2. `MessageTimeline.vue`：行分发（一行一 memo 叶子，分发无条件 hook）+ 根节点 `data-row-id/tool-call-id/status` + 思考→工具→正文恒序保留。
3. `ToolCallCard.vue`：三段式 `ToolSummaryRow + ProgressBar(仅in_progress) + ToolBody + ToolError`；重型内容（diff/图片）进视口才挂载；`pendingApproval` 审批读投影 `pendingInteractions`。
4. 新建 `MarkdownStream`：流式容错未闭合代码块/表格，`completed` 后重排；`data-selectable` 放稳定 DOM 层；复制/fork 走整轮合并文本，只在轮尾显示。
- ⚠️ `early return null` 必须在所有 hook 之后，否则增删行类型必抛 hook 数量不一致。
- ⚠️ 流式 `messageKey=rowId:entityId` 做动画 key，切换任务不复用旧动画。
- ⚠️ 半截 JSON 只进 `inputPreview`，执行只认 `input` 定稿；`FallbackCard` 未知工具显示原文 + `toolName`。
