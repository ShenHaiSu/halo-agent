## 2. 组件契约（props/events/hook）

| 组件 | props | emits | hook 纪律 |
|---|---|---|---|
| `MessageTimeline` | 无（读 `TurnUnit[]` computed + `stuck`） | `link(url)` 外链 | 全部无条件 hook；`setAnchor/nav` 保留 |
| `TurnUnitView` | `unit: TurnUnit; isLastTurn: boolean` | `copy/fork/branch/delete` 透传菜单 | 无条件；`isLastTextBlock` 纯派生 |
| `TextBlockView` | `row: ProjectionRow; hideActions: boolean` | `link` | `MarkdownStream` 在内，无条件 |
| `ReasoningBlock` | `row; defaultCollapsed?=true` | — | hook 后才 `return null`（空流式） |
| `ToolGroupCard` | `group: ToolGroup; defaultCollapsed?=true` | — | 组内 `ToolCallCard` 各自 hook |
| `ToolCallCard` | `row: ProjectionRow`（改对象传参，替代 `card: AgentToolCard`） | `kill/copy/openSub/approve` | `HeaderMemo/BodyLazy` 子组件各自 hook |
| `MarkdownStream` | `text; status: streaming\|completed; rowId; limit?` | `link(href)` | `throttledText` computed 无条件 |

- `ToolCallCard` 传参从 `card: AgentToolCard` 改为 `row: ProjectionRow` 是 breaking change，过渡期保留 `card` 兼容分支（`row ?? toolRowToCard(legacy)`），P1 末删除（`09` 任务）。
- 所有叶子根节点 `data-row-id/data-kind/data-status` 必带；`ToolGroupCard` 另带 `data-gkey/data-count/data-has-failure`。

## 4. CSS/主题/无障碍

- 沿用 `tailwind + naive-ui + CSS var(--reasoning-bg/--tool-output-bg)`，不引入新主题；组头/思考头统一 `h-7` 紧凑行，与现状舱头视觉延续。
