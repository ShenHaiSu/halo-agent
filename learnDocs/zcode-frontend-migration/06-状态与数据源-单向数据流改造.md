# 06 状态与数据源：杀三源、立单向数据流

> 现状三源并存 + `rowIdSeed` 重编 + `hiddenToolCallIds` 遮双写，见 `00 §2.5/2.6`。
> 本篇是风险最高的改造，给出每一步的删除对象、替换接线与回滚开关。

## 1. 目标数据流（单向）

```text
后端 RowProjectionStore.Snapshot/Frame/Range（真 seq/subscriptionId）
  -> hostBridge.getProjectionSnapshot/subscribeFrames/range
  -> projectionStore.onSnapshot/onFrame/mergeRange（唯一写入口）
  -> rowsOf(sessionId) + pendingOf(sessionId)
  -> buildTurnUnits(rows) -> TurnUnit[] (memoBySeq)
  -> MessageTimeline/TurnUnitView 只读渲染

乐观输入：sendPrompt -> pushOptimistic(ghost 行) -> 后端确认 userInput 行到达 -> ackOptimistic（2s 无确认只重订阅不重发）
```

- 组件只读；只有订阅推送能写（`zcodeDocs/05 §1` 三规则）。`agentStore` 瘦身为控制/遥测（`isGenerating/streamingActive/telemetry/turnNotice/lastError/subAgents`），删除 `streamingText/streamingReasoning/toolCards/hiddenToolCallIds/projectedToolCards/refreshFromProjection/dirtyPersisted/lastTurnSnapshot`。
- `workspaceStore.sessionMessages` 降级为历史加载期兼容镜像：`loadSessionMessages` 成功后立刻经 `snapshotFromMessagesDeterministic` 转行并 `onSnapshot`，自身 `sessionMessages` 保留供设置/导出/分支操作读，时间轴禁止读。

## 2. P0 必改：rowId 稳定（不改此条一切 memo 免谈）

现状 `projectionStore.snapshotFromMessages` 用模块级 `rowIdSeed++`（L369），每次重载 rowId 全变。改造：

```ts
// 历史兼容派生（过渡期，后端真快照上线后删除）
function deterministicRowId(msgId: string, salt: string): number {
  // FNV-1a 32bit -> 正整数，稳定跨重载；碰撞时 +1 探查（组装前去重）
  let h = 0x811c9dc5; const s = msgId + '#' + salt;
  for (let i=0;i<s.length;i++){ h ^= s.charCodeAt(i); h = Math.imul(h, 0x01000193); }
  return (h >>> 0) % 1_000_000_000 + 1;
}
// assistant 文本行 salt='text'，reasoning salt='reasoning'，tool salt=callId
```

- 后端真快照上线后，前端 `snapshotFromMessages` 整体删除，只保留 `onSnapshot` 真入口。过渡期双跑 flag `zcode-snapshot-direct`（后端有 `Snapshot()` 即直供，否则本地派生）。
- `rowsToMessages`（L491）保留供导出/分支，但禁止作为渲染输入（删 `MessageTimeline` 对其的间接依赖）。

## 3. 快照直供接线（workspaceStore.loadSessionMessages 改造）

```ts
// workspaceStore.loadSessionMessages(sid) 新逻辑
async function loadSessionMessages(sid: string) {
  loadingMessages.value = true;
  try {
    // 1. 真快照优先
    const snap = await getHostBridge().getProjectionSnapshot(sid, { window: 200 });
    if (snap.ok && snap.data) { useProjectionStore().onSnapshot(snap.data); }
    else { // 2. 回退：messages.jsonl -> 确定性行
      const msgs = await getHostBridge().getSessionMessages(wsId, sid);
      sessionMessages.value = msgs; // 兼容镜像
      useProjectionStore().onSnapshot(snapshotFromMessagesDeterministic(sid, msgs, prevSnap));
    }
    // 3. 订阅增量（幂等 bind）
    bindProjectionSubscription(sid);
  } finally { loadingMessages.value = false; }
}
function bindProjectionSubscription(sid: string) {
  if (bound.has(sid)) return; bound.add(sid);
  getHostBridge().subscribeProjection(sid, {
    onFrame: (f) => enqueueFrame(f),       // 走 05 §2 rAF 队列，不直写
    onResubscribe: () => useProjectionStore().resubscribe(sid),
  });
  useProjectionStore().setResubscribeHandler((id, seq) => getHostBridge().resubscribeProjection(id, seq));
}
```

- `projection:resubscribe` 事件保留（`projectionStore L421` 已有监听重拉），但重拉改为真快照 + `fromSeq` 增量补（后端 `ResubscribeResultDto`，见 `08`），不是全量 `loadSessionMessages`。
- `mergeRange`（早轮加载）接后端 `GetRowsRange`，`hiddenTurnCount` 的“显示更早 N 轮”按钮改为调 `range` 前插（现状 `expandTurnWindow` 只是放行内存截断，改真分页）。
