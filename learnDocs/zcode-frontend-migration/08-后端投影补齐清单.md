# 08 后端投影补齐清单：StreamToRowProjector 还缺什么

> 前端 `02~06` 的多项能力缺数据源，本篇逐项给出后端补齐点。全部位于 `develop/src/Host.Desktop/Services/Projection` + `AgentOrchestrator.cs` 投递分支，不碰网关/协议。

## 1. output.text 流式（终端直播，P1 必做）

- 现状：`StreamToRowProjector` 只有 `OnToolArgsDelta(inputText)`，无 `output` 流式；`AgentOrchestrator` 的工具执行输出只在 `ToolExecutionCompleted.resultText` 一次性发布（L834/938），`exec_command` 长跑期间卡面“等待输出…”。
- 补齐：
  ```csharp
  // StreamToRowProjector 新增
  public IReadOnlyList<ConversationDelta> OnToolOutputDelta(string callId, string outputDelta) {
    // 同 OnToolArgsDelta，但 path=DeltaPaths.OutputText，replayable 档 continuous 才发 delta（与 inputText 同档位）
    // continuous 档 50ms 节流（终端行频高于参数，单独节流窗）
  }
  // AgentOrchestrator 工具执行循环内：进程 stdout/stderr 每行/每 4KB 即调 OnToolOutputDelta + RowProjectionStore 投递
  ```
- `ToolExecutionCompleted` 终态 `OutputText` 截断保持 8000（与前端截断对齐），流式累积不截断（定稿时截）。

## 2. turnHeader state 权威（P0 必做）

- 现状 `AppendTurnHeader(turnIndex)`（L317）只写 `SummaryText=turn-N`，无 `state`，前端 `turnState` 恒 null（`00 §2.7`）。
- 补齐：`ConversationRow` 复用 `State` 字段存 header 状态（`running/completedSuccess/completedInterrupted/failed`），`StreamToRowProjector` 加：
  ```csharp
  AppendTurnHeader(turnIndex, state: "running")       // 轮起
  UpdateTurnHeader(state) -> Upserted                 // 轮终翻转
  ```
- `AgentOrchestrator` 在 `RunAgentTurn` 起/终（`TurnCompleted/Cancelled/Error/Truncated`）调用，前端 `buildTurnUnits.running` 只看此字段（`01 §3`）。

## 3. Continue 复用旧 text 行（P1）

- `zcodeDocs/04 §1` 不变量例外：output-token Continue 可复用同 turn 紧邻旧 `assistantText` 行续写，避免同一句被拆两段。
- 后端实现（前端无感知）：
  ```csharp
  // CompleteText 后若紧接 Continue 且同 turnId 且上一行是 Complete 且无中间 tool，则重开该行为 streaming（Upserted streaming）而非新行
  public IReadOnlyList<ConversationDelta> ReopenLastTextForContinue()
  ```
- 前端只看到标准 `appended/delta/upserted`，`blockKey=rowId` 复用旧行无闪烁。

## 4. 废弃 attempt 收口调用（P0， defense 缺口）

- `InterruptStreamingRows/CancelUnresolvedTools` 已实现（L288-313）但 `AgentOrchestrator` 取消/模型切换路径未调用（`grep CancelUnresolved` 无命中，`00 §6`）。
- 补齐：在 `TurnCancelled/TurnError` 前 + 新 `attempt` 起前调用两者，投递 `upserted(interrupted/cancelled)`。否则旧流续写污染新分支（必现 bug）。

## 5. subagent/artifact 行产出（P1）

- 现状 `subagent/artifact` 行类型已定义但 `StreamToRowProjector` 无产出方法，前端 `SubagentBlock` 无数据源，子进度只走 `agentStore.subAgents` 瞬态（切卡丢失）。
- 补齐：
  ```csharp
  AppendSubagent(subSessionId, label, status) -> Appended
  UpdateSubagent(subSessionId, status, summaryText) -> Upserted
  AppendArtifact(artifactId, displayName, type) -> Appended
  ```
- `SubAgentCoordinator` 事件（`SubAgentsStarted/Progress/Barrier`）同步调以上方法，`spawn_subagent` 工具卡的 `subId` 改读行 `subSessionId`（前端删正则，`06 §4`）。

## 6. state.updated 键（遥测/审批/队列，P1）

- 现状 `ConversationDelta.StateUpdated` 类型已实现但 `RowProjectionStore` 无产出，前端遥测三口径混乱（`00 §2.1`）。
- 补齐键（键级整体替换，不深合并）：
  ```text
  telemetry: { inputTokens, cachedTokens, outputTokens, protocol, ttftMs }  // 每轮 AssistantMessagePersisted/TurnCompleted 推一次
  control: { phase, canStop }                                                // 运行态权威（压缩中不可中断等）
  pendingInteractions: [{ callId, toolName, ticketId, expiresAt }]           // 审批入口权威
  queue: [...]                                                               // 排队项（有则推）
  confirmedCommands: [commandId]                                             // 乐观确认（06 §5）
  ```
- 前端 `pendingOf/telemetry` 只读此键，不读行文本/旧事件。

## 7. seq/订阅/断档裁决（P0，加固）

- `RowProjectionStore` 已有 `Snapshot/Range/Resubscribe` 骨架（`grep` 见 `00 §2.7`），补齐细节：
  - `seq` 全局会话单调（`DeltaLog` 每 delta +1），`Snapshot.seq` = 已投递最大 seq，`Frame{fromSeq,toSeq,deltas}` equence 连续。
  - `Resubscribe(fromSeq)`：若 `fromSeq` 在 `DeltaLog` 窗内 → 返回缺口 deltas；否则返回全量 Snapshot（服务端裁决，前端不猜，`zcodeDocs/05 §1`）。
  - `Snapshot(window)` 缺省近 200 行 + `totalCount/firstRowId`（`hasOlderRows` 分页，前端 `mergeRange` 前插）。
- `HostBridgeFacade.Projection.cs` 暴露 `getProjectionSnapshot/subscribeFrames/resubscribeProjection/getRowsRange` 四方法（前端 `06 §3` 依赖）。

## 8. 空工具名与媒体（沿用 zcodeDocs/02 纪律，后端确认）

- 空 `toolName` 投影边界占位 `empty_tool_name`（`StreamToRowProjector L176` 已正确），历史保留原文，前端 `FallbackCard` 显示原文。
- `view_image` 的 `images` 数组经 `extra.images` 透传（前端已读 `card.images`），`relPath` 不嵌 base64（`exportSessionMarkdown` 纪律）。
